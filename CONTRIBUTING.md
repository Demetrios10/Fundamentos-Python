# Desenvolvimento e contribuição

Este repositório é uma trilha de estudo com exemplos independentes. Preserve a finalidade didática, a numeração e os links do índice ao propor mudanças.

## Verificar uma alteração

1. Execute a aula modificada no terminal com entradas válidas e inválidas pertinentes.
2. Mantenha a interação dentro de `main()` e a guarda `if __name__ == "__main__"`.
3. Execute `python -m unittest discover -s tests -v` na raiz.
4. Atualize o índice e o README se houver mudança de conteúdo ou organização.

Use dados fictícios e não adicione senhas reais. Ao registrar uma execução, informe data, versão do Python, sistema, comando e resultado. Diferencie resultado observado de cobertura planejada. Não substitua relatórios históricos por resultados não executados.

As aulas atuais não exigem bibliotecas externas. Explique a necessidade e o impacto didático antes de introduzir uma dependência.
